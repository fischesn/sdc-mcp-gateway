# v0.6.1 Specification: Benchmark Aggregation

Version 0.6.1 adds a small aggregation utility for benchmark result files produced by `sdc-mcp-gateway benchmark`.

## Goal

The goal is to turn several `.summary.json` benchmark outputs into one machine-readable aggregate report and one CSV table that can be used for later paper tables and plots.

## New command

```powershell
sdc-mcp-gateway summarize-benchmarks --input-dir data/experiment_runs --label simulated-v06-summary
```

The command searches the input directory for files matching `*.summary.json` by default.

Optional parameters:

```powershell
sdc-mcp-gateway summarize-benchmarks \
  --input-dir data/experiment_runs \
  --output-dir data/experiment_runs \
  --label simulated-v06-summary \
  --pattern "simulated-v06-run*.summary.json"
```

## Outputs

The command writes:

```text
data/experiment_runs/<label>-<timestamp>.aggregate.json
data/experiment_runs/<label>-<timestamp>.aggregate.csv
```

The aggregate JSON contains:

- number of summarized runs
- run identifiers
- status values
- adapter and mapping-version values
- safety-boundary status
- total read-error count
- per-run rows
- aggregated latency values for all benchmark latency blocks

The aggregate CSV contains one row per benchmark summary file.

## Safety interpretation

The aggregate report preserves the safety-boundary checks from the individual runs. The aggregate field `safety_boundary_ok` is true only if every summarized run reports:

```json
{
  "all_read_only": true,
  "tools_exported_any": false,
  "write_operations_allowed_any": false
}
```

## Scope

This is an offline result aggregation utility. It does not start SDC consumers, MCP servers, or simulated providers.
