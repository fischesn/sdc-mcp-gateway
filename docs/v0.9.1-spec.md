# v0.9.1 Specification: Gemini-backed agent evaluation

Version v0.9.1 adds an optional Gemini-backed LLM evaluation mode.

## New agent mode

```text
llm-gemini
```

The mode uses Google's `google-genai` SDK and the Gemini Developer API. The dependency is optional and is imported only when the Gemini backend is selected.

## Installation

```powershell
python -m pip install -e ".[gemini]"
```

or:

```powershell
python -m pip install -e ".[all]"
```

## Credentials

Set one of:

```powershell
$env:GEMINI_API_KEY = "..."
$env:GOOGLE_API_KEY = "..."
```

Alternatively pass `--llm-api-key-env` with the name of a custom environment variable.

## Example

```powershell
sdc-mcp-gateway evaluate-agent-tasks `
  --config config/gateway.simulated.tachycardia.example.yaml `
  --mie config/sdc_mie.yaml `
  --tasks config/agent_eval.tasks.yaml `
  --scenario tachycardia `
  --agent llm-gemini `
  --llm-model gemini-2.5-flash `
  --output-dir data/agent_eval `
  --elapsed-s 100
```

## Safety boundary

The Gemini agent receives only read-only resource context. MCP tools remain disabled and no SDC write operations are exposed.
