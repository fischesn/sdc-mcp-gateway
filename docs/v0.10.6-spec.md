# v0.10.6: Dry-run tool evaluation

Version v0.10.6 adds a systematic evaluation command for the dry-run MCP tool surface.

## Command

```powershell
sdc-mcp-gateway evaluate-dry-run-tools `
  --config config/gateway.simulated.dryrun.example.yaml `
  --ack-config config/gateway.simulated.dryrun.high-airway-pressure.example.yaml `
  --mie config/sdc_mie.yaml `
  --tool-policy config/tool_policies.yaml `
  --output-dir data/tool_eval `
  --label dryrun-tools-v0106
```

## Evaluation cases

The default case set covers:

| Case | Expected result |
|---|---|
| valid FiO2 45% | accepted dry-run |
| invalid FiO2 150% | rejected, value out of range |
| valid PEEP 10 cmH2O | accepted dry-run |
| invalid PEEP 50 cmH2O | rejected, value out of range |
| PEEP proposal for monitor | rejected, wrong device type |
| acknowledge active airway alarm | accepted dry-run |
| acknowledge inactive/missing airway alarm | rejected |

## Safety invariant

Every case must preserve:

```json
{
  "executed": false,
  "write_operations_allowed": false
}
```

The evaluation is intentionally not a real SDC operation test. It only validates action proposals against local dry-run policies and audit logging.
