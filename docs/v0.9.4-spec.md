# v0.9.4 Specification: Agent-Evaluation Aggregation

Version 0.9.4 adds an aggregation utility for agent-facing evaluation runs. Earlier versions can run oracle and LLM-backed task evaluations and write one JSON/CSV/Markdown report per scenario. This release adds a command that summarizes multiple agent-evaluation JSON files into a single aggregate JSON and CSV table.

## Scope

The aggregation utility is intended for repeated oracle, mock-LLM, Gemini, Ollama, or OpenAI-compatible evaluations. It does not call an LLM and does not interact with SDC devices. It only reads previously generated agent-evaluation JSON reports.

## Command

```powershell
sdc-mcp-gateway summarize-agent-evaluations `
  --input-dir data/agent_eval `
  --label gemini-v093-summary `
  --pattern "agent-eval-*.json"
```

The command generates:

```text
<data-dir>/<label>-<timestamp>.aggregate.json
<data-dir>/<label>-<timestamp>.aggregate.csv
```

## Aggregated Metrics

The aggregate report includes:

- number of runs,
- scenarios,
- agent backends and models,
- total/passed/failed tasks,
- pass rate,
- per-task pass counts,
- wrong URI selections,
- hallucinated or missing devices,
- false positive and false negative alarm counts,
- unsafe-term counts in clinical summaries,
- read-only safety-boundary status.

## Safety Boundary

The command verifies that all included runs retained the read-only boundary:

```json
{
  "mode": "read-only",
  "tools_exported": false,
  "write_operations_allowed": false
}
```

The aggregation utility does not expose MCP tools and cannot trigger write operations.
