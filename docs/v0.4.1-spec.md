# v0.4.1 Specification: MCP Smoke Test Utility

## Purpose

Version v0.4.1 adds a lightweight local smoke-test command for the read-only MCP
resource surface. The command is intended to reduce ambiguity when the stdio MCP
server appears to "do nothing" in an interactive terminal. In stdio mode this is
normal: the server waits for MCP client requests. The smoke test verifies the
same registry and resource surface without requiring a human to manually speak
JSON-RPC over stdin/stdout.

## Command

```bash
sdc-mcp-gateway mcp-smoke-test --config config/gateway.simulated.example.yaml --mie config/sdc_mie.yaml
```

Optional strict mode:

```bash
sdc-mcp-gateway mcp-smoke-test --config config/gateway.simulated.example.yaml --mie config/sdc_mie.yaml --require-mcp-sdk
```

## Checks

The command checks that:

1. the selected adapter can create a registry,
2. resources are listed,
3. every advertised resource can be read,
4. `sdc://health` reports read-only mode,
5. no MCP tools are exported,
6. no write operations are allowed,
7. the health resource count matches the catalogue,
8. `sdc://resources` is readable,
9. a FastMCP server can be constructed when the optional MCP SDK is installed.

## Safety boundary

v0.4.1 remains strictly read-only. It does not add MCP tools, does not expose SDC
write operations, and does not execute any device command.

## Non-goals

- no long-running event subscription,
- no dynamic refresh of server state,
- no dry-run tool generation,
- no SDC write operation execution,
- no clinical use.
