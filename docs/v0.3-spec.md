# v0.3.0 Specification: Simulated SDC-like Provider Testbed

## Purpose

Version 0.3.0 adds a reproducible, in-process simulation layer so that the gateway can be developed and tested without access to a real SDC network. The simulator generates normalized device snapshots that use the same internal data model as the real SDC adapter.

This version is still strictly read-only. It does not expose write operations and it does not execute device commands.

## Scope

Included:

- YAML-based simulation scenarios.
- Simulated patient monitor scenario.
- Simulated ventilator scenario.
- Combined multi-device scenario.
- `simulated` SDC adapter for the gateway.
- `simulate-snapshot` CLI command.
- Mapping through the regular SDC-MIE mapping layer.
- Audit/measurement logging for simulated discovery and snapshots.
- Unit tests for the simulation layer.

Not included:

- A real IEEE 11073 SDC provider implementation.
- WS-Discovery simulation on the network.
- Event streaming.
- MCP Tools for write operations.
- Human-in-the-loop execution paths.

## Simulation model

A scenario YAML file contains one or more simulated devices. Each device contains metrics and alarm rules. Metric values are generated as:

```text
value(t) = baseline + amplitude * sin(2*pi*t/period_s) + noise
```

Values are clipped by optional `min_value` and `max_value` bounds. Alarms are evaluated against optional high and low thresholds.

## Example commands

Generate a mapped snapshot directly from a scenario:

```bash
sdc-mcp-gateway simulate-snapshot \
  --scenario config/sim.combined.yaml \
  --elapsed-s 10 \
  --mie config/sdc_mie.yaml
```

Use the simulation through the regular gateway adapter path:

```bash
sdc-mcp-gateway discover --config config/gateway.simulated.example.yaml
sdc-mcp-gateway snapshot --config config/gateway.simulated.example.yaml --mie config/sdc_mie.yaml
```

Serve MCP resources backed by simulated devices:

```bash
sdc-mcp-gateway serve --config config/gateway.simulated.example.yaml --mie config/sdc_mie.yaml
```

## Rationale

The simulation layer supports reproducible experiments before access to real SDC-capable devices is available. It can be used to validate:

- resource naming,
- SDC-MIE mapping,
- logging and measurement instrumentation,
- multi-device snapshots,
- alarm-state representation,
- future agent interactions against deterministic test data.

Real SDC networking remains the role of the `sdc11073` adapter introduced in v0.2.1.
