# v0.10.7 Specification: Example MCP Clients

Version v0.10.7 adds small Python examples showing how to use the gateway from custom
MCP clients and simple agent programs.

## Added examples

- `examples/mcp_client_common.py` -- shared stdio MCP client helpers.
- `examples/mcp_client_read_resources.py` -- lists and reads MCP resources.
- `examples/mcp_client_call_dryrun_tool.py` -- calls a dry-run MCP tool.
- `examples/agent_mcp_client_demo.py` -- deterministic agent-style demo using MCP resources and dry-run tools.

## Added documentation

- `docs/MCP_CLIENT_EXAMPLES.md`

## Scope

The examples use the stdio MCP transport. They do not add a network MCP server. Network
server support is intentionally deferred to a later v2 line.

## Safety boundary

The examples preserve the existing safety boundary. Resource examples are read-only.
Dry-run tool examples call policy-checked tools that must not execute SDC operations.


## Real SDC documentation addendum

The v0.10.7 documentation set includes `docs/REAL_SDC_TESTING.md`, which prepares first read-only validation in a real SDC/VPN/lab network. This is documentation-only and does not add network-facing MCP transport.
